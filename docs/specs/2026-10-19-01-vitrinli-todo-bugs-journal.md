## Closeout

- root_cause:
  - Restricted views scaled each region independently with `ceilf`, while `info.json` reported clamped dimensions in a coordinate space the renderer did not use. That caused tile seams (DEV-7456) and wrong regions (DEV-7485).
  - `info.json` hard-coded `ACAO: *`, which fails credentialed browser fetches (DEV-7520).
  - `SipiIOJ2k::read` requested component 0's stripe height from subsampled chroma, so Kakadu spun forever (DEV-7432). The YCbCr conversion also assumed a fixed channel order.
  - `Exif::addKeyVal` appended duplicates, and `findKey` returned the first (DEV-7431).
  - JPEG `open()` lacked `O_TRUNC` (DEV-6211).
  - Restricted outputs copied metadata that carried the native size and previews.
  - JPEG output dropped IPTC and oversized metadata blocks.
- investigation:
  - The JP2 hang reproduced on the CLI. A stack sample pinned it to `kdu_stripe_decompressor::pull_common`. `file2.jp2`, the same image without subsampling, ruled out sYCC.
  - The restricted-view redesign went through five review passes. They surfaced the passthrough leak, the memory-budget undercount, the 1 px axis, the empty-watermark bypass and the cache-key collision.
  - A final exiftool measurement found the native size in EXIF/XMP of restricted outputs.
  - DEV-6361 (FlashEnergy) was confirmed not-a-bug against libtiff 4.7.2. DEV-6118 did not reproduce, and a regression test now pins it.
- solution:
  - Restricted dims are decided once in the Rust shell and cross the FFI as two `uint32_t` fields.
  - A size-restricted image is served as its own image of `(RW, RH)` (ADR-0028): one decode, crop, `maxWidth`/`maxHeight`, and a `/r<RW>x<RH>` cache key.
  - `info.json` CORS goes through `json_cors`, always with `Vary: Origin`.
  - Subsampled JP2 uses a planar pull with co-sited replication and a guard. Channel order comes from `jp2_channels`.
  - `addKeyVal` erases before it adds. The JPEG write truncates.
  - Restricted metadata gets its dimension fields rewritten and its previews dropped. Rights are kept.
  - JPEG output writes valid APP13, splits oversized XMP and IPTC, and leaves out only unfittable blocks, with a warning.
  - `just compile-commands` (the helly25 hedron fork) gives clangd and clang-tidy a compile database.
- prevention:
  - e2e seam, region, refusal, CORS and metadata tests. serve_image_test covers restricted geometry and the cache key. formats_test covers JP2 subsampling, channel order and JPEG metadata segments. Fuzz seeds include a subsampled JP2.
  - ADR-0028 records the restricted-view coordinate space.
  - Follow-ups:
    - DEV-7572: SIPI-2 analysis.
    - DEV-7575: toolchain upgrades.
    - DEV-7588: macOS coverage.
    - Plan H7: abandoned deadline threads, CORS on errors, `Vary` on the image route, the `null` Origin, the watermark identity in the cache key, the Tile-lane residual, and linear chroma upsampling.
    - Journal deferrals: the ExtendedXMP reader, rights held only in raw EXIF copies, and the metadata size cap.
