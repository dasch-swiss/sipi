  - Upstream source reads settled three open questions. rules_rust #4101 (0.71.0) prefixes `-isysroot`, so that patch was dropped. hermetic-llvm 0.8.25 still declares the kernel and glibc headers as a bare directory, so the headers-glob patch was kept and rebased; the path A/B aquery file checks confirmed it. 0.8.25 still lists LLVM 22.1.7.
